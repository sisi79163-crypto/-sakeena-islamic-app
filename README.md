# سكينة | Sakeena

تطبيق ويب إسلامي عربي يعمل كتطبيق تقدمي PWA، ومهيأ للنشر على GitHub Pages من دون خادم أو مفاتيح سرية.

## الوظائف

- مصحف من 604 صفحات مع السحب، حفظ آخر قراءة، تحديد الآيات والتلاوة الصوتية المتتابعة.
- تسميع صوتي وتصحيح تقريبي كلمة بكلمة في المتصفحات التي تدعم Web Speech Recognition.
- مواقيت الصلاة حسب الموقع مع عدّاد للصلاة القادمة.
- اتجاه القبلة مع دعم بوصلة الهاتف.
- أذكار الصباح والمساء والنوم مع عدادات محفوظة محلياً.
- مسبحة، حاسبة زكاة، ودليل قرآني موضوعي محلي.
- منبّه فجر مع اهتزاز ومسألة حسابية عند بقاء التطبيق مفتوحاً.
- وضع ليلي، تثبيت كتطبيق، وتخزين محلي بلا حساب مستخدم.

## التشغيل محلياً

لا يحتاج المشروع إلى تثبيت حزم. شغّله من خادم محلي حتى تعمل خصائص PWA:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر

المشروع يتضمن سير عمل داخل `.github/workflows/deploy-pages.yml`. بعد رفعه إلى فرع `main`:

1. افتح `Settings` ثم `Pages` في المستودع.
2. اختر `GitHub Actions` كمصدر النشر إن لم يكن محدداً.
3. شغّل سير العمل أو ادفع تعديلاً جديداً إلى `main`.

## مصادر البيانات

- نص القرآن والتلاوة: Al Quran Cloud API.
- مواقيت الصلاة: AlAdhan Prayer Times API باستخدام طريقة رابطة العالم الإسلامي.
- اتجاه القبلة: يحسب داخل الجهاز انطلاقاً من الإحداثيات.

## حدود المنصة

GitHub Pages يستضيف موقعاً ثابتاً. لذلك لا يمكن ضمان تشغيل منبّه الويب بعد إغلاق المتصفح أو عند تعليق iOS للتطبيق. التنبيه الدائم في الخلفية يحتاج تطبيق iOS/Android أصلياً أو خادماً للإشعارات.
