# مَشهد | Mashhad

محرّر فيديو عربي يعمل **بالكامل داخل المتصفح**. لا خادم، ولا حساب، ولا رفع ملفات: كل مقطع تفتحه يبقى على جهازك، والتصدير يجري محلياً عبر واجهات المتصفح القياسية.

## الوظائف

- **استيراد محلي** للفيديو والصور والصوت بالسحب والإفلات أو من زر الاستيراد.
- **شريط زمني** بمسار مرئي ومسار نصوص ومسار موسيقى، مع تكبير وتصغير.
- **قصّ وترتيب**: سحب المقاطع لإعادة ترتيبها، وسحب أطرافها للقصّ، وقصّ عند المؤشر بضغطة واحدة.
- **نصوص فوق الصورة** مع تحكم كامل: الخط، الحجم، اللون، المحاذاة، الحدّ الأسود، الخلفية، والموضع.
- **فلاتر لونية** لكل مقطع: السطوع، التباين، التشبّع، الضبابية، سيبيا، تدرّج رمادي، ودوران اللون.
- **تحكم بالسرعة والصوت** لكل مقطع، وموسيقى خلفية بمستوى صوت مستقل.
- **أبعاد جاهزة** للمنصات: ‎16:9 و‎9:16 و‎1:1 و‎4:5.
- **تصدير** إلى ملف فيديو مع الصوت، بجودة ومعدل بِت قابلين للاختيار.
- **حفظ تلقائي** لبنية المشروع داخل المتصفح، ويعمل دون إنترنت بعد أول زيارة.

## التشغيل محلياً

المشروع بلا حزم ولا خطوة بناء، لكنه يستخدم وحدات ES، لذا يحتاج خادماً محلياً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر على GitHub Pages

الملف `.github/workflows/deploy-pages.yml` ينشر المشروع تلقائياً عند الدفع إلى `main`:

1. افتح `Settings` ثم `Pages` في المستودع.
2. اختر `GitHub Actions` مصدراً للنشر.
3. ادفع تعديلاً إلى `main` أو شغّل سير العمل يدوياً.

## كيف يعمل التصدير

يرسم المحرّك كل إطار على `<canvas>`، ويُلتقط الناتج عبر `canvas.captureStream()`. أصوات المقاطع والموسيقى تمرّ عبر رسم `Web Audio` إلى `MediaStreamDestination`، ثم يُدمج المساران في `MediaRecorder`.

نتيجة هذا الاختيار:

- **التصدير يجري بزمن حقيقي.** مشروع مدته دقيقتان يستغرق دقيقتين، ويجب إبقاء التبويب ظاهراً حتى ينتهي، لأن المتصفح يبطّئ التبويبات المخفية.
- **صيغة الملف تتبع المتصفح**: WebM على Chrome و Edge و Firefox، و MP4 على Safari الحديث.
- لا حاجة إلى `ffmpeg.wasm` أو أي تنزيل ثقيل، والمقابل أننا لا نستطيع الترميز أسرع من الزمن الحقيقي.

## الخصوصية

لا يغادر أي ملف جهازك. الوسائط تُقرأ عبر `object URL` وتبقى في ذاكرة التبويب، ولا يُحفظ في المتصفح سوى بنية التحرير (المدد، النصوص، الفلاتر) لاستعادة المشروع لاحقاً. عند إعادة فتح المحرّر ستحتاج إلى إعادة اختيار ملفات الوسائط بالأسماء نفسها ليعاد ربطها تلقائياً.

## حدود معروفة

- التصدير يحتاج `MediaRecorder` مع `canvas.captureStream` — متوفر في المتصفحات الحديثة على سطح المكتب، ومتفاوت على المتصفحات القديمة.
- مسار مرئي واحد: المقاطع متتابعة بلا فجوات أو طبقات فوق بعضها. النصوص والموسيقى لها مساراتها المستقلة.
- لا توجد انتقالات (Transitions) بين المقاطع بعد.
